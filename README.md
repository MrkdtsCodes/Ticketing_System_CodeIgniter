# Ticketing_System_CodeIgniter

A personal ticketing system project built with PHP, CodeIgniter, jQuery, MySQL, and Tailwind CSS.

This project is an ongoing improvement of my previous ticketing system implementation, where I applied concepts and development practices I learned while working with a professional CRM codebase.

Features
Ticket creation and management
Ticket filtering by status, priority, and assigned employee
AJAX-based filtering and dynamic content updates
Server-side pagination
Database-driven ticket records
CodeIgniter MVC architecture
Form handling and request validation
